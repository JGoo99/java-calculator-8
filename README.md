# 요구 사항

- [x] : 기능 목록 작성하기
- [ ] : 쉼표(,) 또는 콜론(:)을 구분자로 가지는 문자열을 전달하는 경우 구분자를 기준으로 분리한 각 숫자의 합을 반환한다.
- [ ] : "//;\n1;2;3"과 같이 값을 입력할 경우 커스텀 구분자는 세미콜론(;)이며, 결과 값은 6이 반환되어야 한다.
- [ ] : 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료되어야 한다.

<br/>

# 세부 기능 목록

### 1. 동작하는 쓰레기 만들기

- [x] : 쉼표(,) 또는 콜론(:)을 구분자와 양수로 이루어진 문자열을 전달하는 경우 각 숫자의 합을 반환한다.
- [x] : "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 추출한다.
- [x] : 커스텀 구분자와 양수로 이루어진 문자열을 전달하는 경우 각 숫자의 합을 반환한다.

<br/>

### 2. 예외 케이스 잡기

> IllegalArgumentException 을 발생시킨 후 종료한다.

- [x] : 음수가 포함된 경우
- [x] : 커스텀 구분자의 regex 가 다른 경우
- [ ] : 숫자로 끝나지 않는 경우
- [ ] : 숫자나 "//" 로 시작하지 않는 경우
- [ ] : 정수 범위를 넘어가는 경우

<br/>

> 종료는 아님.

- [ ] : "//;\n" 의 경우 0 반환
